# 湿地灯光试验的观测证据与分区调整

业务资料均为合成记录。表头字段及跨表引用见 `fixtures/format.json`。

## 数据说明

排期中的 zone 与路径编号通过 paths 对应。一条站点记录列出的路径是可能改变读数的照明源，`-` 表示未登记任何照明干扰。对比分别查看明亮、低照度及执行偏离，match 是事先登记的候选而非配对已通过的标记。相同夜号共享天气。夜号从第一个观测日起算，known_night 表示当晚之后才可用。校准有效期含两端，后来的校准说明只在给定区间覆盖同标识原记录。
雨天不作亮度比较，cloud 与 clear 分开。安全下限为路径应急照度，巡查不完整的片区仍保留原档；operations 中签准窗表明签准所引用的观测，不等同于现场排期。亮度以 mag/arcsec² 表示，每增加 5 单位对应通量减为原来的百分之一。

CSV 使用 UTF-8、逗号分隔，无引号与内嵌换行。未提供的字段是空字符串，作为关系值的 `-` 表示不适用。多值字段用竖线分隔，数值和日期单位见业务约定。

## 资料检查

使用 Node.js 22.23.4，依赖仅为 Node.js 标准库。运行 `npm ci --ignore-scripts --offline` 准备工作区。
